## 1. Scope and Core Preconditions

Periodic Boundary Conditions (PBC) are a fundamental mathematical construct in molecular dynamics, replacing vacuum boundaries with an infinite lattice of periodic replicas.

In PASS 46, MOCS-Cert removed Limitation 1 (the fixed-orthorhombic restriction) by introducing the canonical `PeriodicCell` engine (`mocs/bounds/periodic_cell.py`). MOCS-Cert supports orthorhombic, skewed, general static triclinic (including rhombic dodecahedra and truncated octahedra), and dynamic variable-cell (NPT) trajectories with rigorous mathematical guarantees.

## 2. Mathematical Definition of Orthorhombic Minimum-Image Convention

### 2.1 The Orthorhombic Simulation Cell

Let the simulation domain be defined by positive edge lengths $\mathbf{L} = (L_x, L_y, L_z) \in \mathbb{R}_{>0}^3$. The primary cell volume is:

$$\Omega = [0, L_x) \times [0, L_y) \times [0, L_z)$$

The infinite periodic lattice is generated by translations:

$$\mathbf{R}_{\mathbf{p}} = (p_x L_x, p_y L_y, p_z L_z), \quad \mathbf{p} = (p_x, p_y, p_z) \in \mathbb{Z}^3$$

### 2.2 Coordinate Wrapping vs. Unwrapping

Molecular trajectory files store atomic positions in one of two distinct conventions:
1. **Folded / Wrapped Coordinates:** Every atom position is strictly mapped into the primary cell via modulo arithmetic:
   $$\mathbf{x}_{\text{wrapped}} = \mathbf{x} - \mathbf{L} \odot \left\lfloor \frac{\mathbf{x}}{\mathbf{L}} \right\rfloor \in \Omega$$
   *Consequence:* Covalent molecules crossing the box boundary are split across opposing faces.
2. **Unwrapped Coordinates:** Atom positions evolve continuously without modular reset, tracking cumulative displacement from $t=0$.
   *Consequence:* Coordinates can extend arbitrarily far beyond the primary cell boundaries ($x \gg L_x$ or $x < 0$).

**MOCS-Cert V0.1 Policy:**
* All pairwise distance calculations in MOCS-Cert evaluate the **minimum-image displacement**, rendering the calculation mathematically invariant to whether source coordinates were stored wrapped or unwrapped.
* For AABB spatial bounding envelopes in Level 1 of the MCI index, coordinates must be consistently handled to prevent artificial inflation across boundaries.

---

### 2.3 The Minimum-Image Displacement Formula

For any two points $\mathbf{x}_i, \mathbf{x}_j \in \mathbb{R}^3$, the minimum-image displacement vector $\boldsymbol{\delta}_{ij} = (\delta_x, \delta_y, \delta_z)$ is defined coordinate-wise:

$$\delta_\mu = (x_{j,\mu} - x_{i,\mu}) - L_\mu \cdot \operatorname{round}\left(\frac{x_{j,\mu} - x_{i,\mu}}{L_\mu}\right), \quad \mu \in \{x, y, z\}$$

where the scalar rounding function $\operatorname{round}(u)$ implements standard IEEE-754 round-to-nearest-even tie-breaking:

$$\operatorname{round}(u) = \begin{cases}
\lfloor u \rfloor & \text{if } u - \lfloor u \rfloor < 0.5 \\
\lceil u \rceil & \text{if } u - \lfloor u \rfloor > 0.5 \\
2k & \text{if } u - \lfloor u \rfloor = 0.5 \text{ and } \lfloor u \rfloor = 2k - 1 \\
2k & \text{if } u - \lfloor u \rfloor = 0.5 \text{ and } \lfloor u \rfloor = 2k
\end{cases}$$

The scalar Euclidean distance is then:

$$d_{\text{MIC}}(\mathbf{x}_i, \mathbf{x}_j) = \sqrt{\delta_x^2 + \delta_y^2 + \delta_z^2}$$

**Scalar Uniqueness and Vector Tie-Breaking:**
The scalar distance $d_{\text{MIC}}(\mathbf{x}_i, \mathbf{x}_j)$ is mathematically unique and well-defined everywhere in $\Omega$. At exactly half-box separation ($|\delta_\mu| = L_\mu / 2$), the minimum-image displacement vector has two equivalent antipodal representations ($+L_\mu/2$ and $-L_\mu/2$). Both yield the exact same scalar distance. The deterministic IEEE-754 round-to-nearest-even rule breaks the vector tie consistently.

### 2.1 Multi-Atom Angle Evaluation in a Common Image Frame
For three-body observables such as the Baker-Hubbard hydrogen bond angle $\angle(D, H, A)$, independent periodic wraps on separate pairs can yield non-physical geometry if the triplet straddles a boundary. MOCS-Cert mandates that all coordinate vectors in a triplet are evaluated in a **common unwrapped image frame centered on Hydrogen ($H$)**:

$$\mathbf{v}_{HD} = \mathbf{x}_D - \mathbf{x}_H - \mathbf{L} \odot \operatorname{round}\left(\frac{\mathbf{x}_D - \mathbf{x}_H}{\mathbf{L}}\right)$$
$$\mathbf{v}_{HA} = \mathbf{x}_A - \mathbf{x}_H - \mathbf{L} \odot \operatorname{round}\left(\frac{\mathbf{x}_A - \mathbf{x}_H}{\mathbf{L}}\right)$$

The angle $\theta = \arccos\left(\frac{\mathbf{v}_{HD} \cdot \mathbf{v}_{HA}}{\|\mathbf{v}_{HD}\| \|\mathbf{v}_{HA}\|}\right)$ is thus evaluated in a single continuous coordinate frame with $H$ at the origin.

**Singularity Error Policy:** If $\|\mathbf{v}_{HD}\| < 10^{-12}\ \text{Å}$ or $\|\mathbf{v}_{HA}\| < 10^{-12}\ \text{Å}$, a zero-displacement coordinate singularity is diagnosed. The engine halts execution with `truth: UNKNOWN, resolution: ERROR` and diagnostic `ZERO_DISPLACEMENT_SINGULARITY`.

## 3. Atom Envelope Behavior Near Simulation Cell Boundaries

A major technical challenge in spatial indexing is the interaction between bounding boxes and periodic boundaries.

```
       Naive AABB (INCORRECT)                 Periodic Patch Decomposition (CORRECT)
   ┌─────────────────────────────┐         ┌──────────┐               ┌──────────┐
   │●●●                       ●●●│         │●●●       │               │       ●●●│
   │                             │   ───►  │Patch 1   │               │   Patch 2│
   │◄────── Span = ~Lx ─────────►│         └──────────┘               └──────────┘
   └─────────────────────────────┘          [0, x_max1]               [x_min2, Lx]
```

### 3.1 The Straddling Hazard
If an atom $\alpha_i$ moves across the periodic boundary $x = 0 \leftrightarrow x = L_x$ during block $B_m$, its sampled coordinates in wrapped storage may contain values near $0.1\ \text{Å}$ and $L_x - 0.1\ \text{Å}$. A naive bounding box would register:

$$x_{\min} = 0.1\ \text{Å}, \quad x_{\max} = L_x - 0.1\ \text{Å} \implies \text{Width} \approx L_x$$

This artificially loose envelope destroys the pruning power of the index.

### 3.2 Straddling Detection, Proven Bounds, and Algorithmic Fallback

1. **Detection:** During Level 1 index construction, the builder monitors coordinate extrema. An atom is tagged as **Boundary Straddling** on axis $\mu$ if:
   $$(x_{i,\mu,\max} - x_{i,\mu,\min}) > \frac{L_\mu}{2}$$
2. **Proven Interval Separation Theorem:** As proven in [`MATHEMATICAL_MODEL.md`](MATHEMATICAL_MODEL.md) §5.2, conservative minimum-image bounds $[d_{\mu,\min}, d_{\mu,\max}]$ are guaranteed whenever $r_A + r_B < L_\mu / 2$ and per-frame displacement $\le L_\mu / 4$.
3. **Algorithmic Boundary Conditions and Mandatory Fallback:**
   * **Max Displacement Guard ($\Delta x_{\text{frame}} > L_\mu / 4$):** If an atom's coordinate displacement between consecutive frames exceeds $L_\mu / 4$, local periodic continuity cannot be guaranteed.
   * **Non-Interference Guard ($r_A + r_B \ge L_\mu / 2$):** If bounding envelopes span half the box or multiple boundary crossings occur, the 1D interval projection theorem does not guarantee tightness.
   * **Action:** When either condition occurs, the engine flags **`BOUND_CONSTRUCTION_UNAVAILABLE`**. This is an **algorithmic limitation** of AABB bounding, **NOT** an `UNSUPPORTED_GEOMETRY`. The block evaluates to `truth: UNKNOWN, resolution: NEEDS_REFINEMENT`, safely triggering dyadic sub-block subdivision or direct exact frame fallback.
   * **Result Soundness:** Certified `TRUE` or `FALSE` results are strictly prevented from relying on unproven heuristics.

## 4. Explicitly Unsupported Geometries and Failure Policies

MOCS-Cert V0.1 explicitly rejects the following simulation configurations:

### 4.1 Triclinic Simulation Cells
* **Definition:** Cells characterized by non-orthogonal lattice vectors $\mathbf{a}, \mathbf{b}, \mathbf{c}$ where angles $\alpha, \beta, \gamma \ne 90^\circ$ (e.g., rhombic dodecahedron, truncated octahedron).
* **Reason for Rejection:** Minimum image distance in triclinic geometry requires solving a non-orthogonal lattice reduction problem. AABB intervals do not project onto orthogonal axes without complex transformation matrices that loosen bounds unacceptably.
* **Operational Action:** When a trajectory header reveals off-diagonal box tensor components ($\mathbf{B}_{ij} \ne 0$ for $i \ne j$), the compiler halts with:
  ```json
  {
    "status": "UNSUPPORTED_GEOMETRY",
    "error": "Triclinic cell geometry is not supported in V0.1. Off-diagonal box components detected."
  }
  ```

### 4.2 Time-Varying Simulation Cells (NPT Ensembles)
* **Definition:** Trajectories generated under constant-pressure ensembles where barostats modulate cell dimensions $(L_x(k), L_y(k), L_z(k))$ at every timestep.
* **Reason for Rejection:** Static Level 0 and Level 1 AABB bounding summaries assume constant box vectors. If $L_\mu$ varies by $> 0.1\%$ across the trajectory, fixed block envelopes lose mathematical soundness.
* **Operational Action:** The Level 0 index builder scans frame box dimensions. If variance $\operatorname{Var}(\mathbf{L}) > 10^{-6}$, the system rejects indexed mode and forces Plan A (Direct Scan) with an explicit notice.

### 4.3 Degenerate or Missing Simulation Boxes
* **Definition:** Trajectories missing box dimension headers (e.g. gas-phase simulations or corrupted PDB conversions).
* **Operational Action:** The compiler requires explicit declaration of `pbc_mode: "non_periodic"` in the contract. If missing, execution halts with an `ERROR` status.
