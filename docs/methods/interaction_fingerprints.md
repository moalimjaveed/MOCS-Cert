# Method Specification: Non-Covalent Interaction Fingerprints
## Method ID: METH-005

### 1. Scientific Overview
Generates binary interaction bitvectors capturing non-covalent contacts:
1. Hydrogen bonds ($d \le 3.5	ext{ \AA}$, $	heta \ge 120^\circ$)
2. Hydrophobic contacts ($d \le 4.5	ext{ \AA}$)
3. Pi-stacking ($d \le 5.5	ext{ \AA}$)
4. Salt bridges ($d \le 4.0	ext{ \AA}$)
