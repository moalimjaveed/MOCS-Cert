## 1. Epistemic Hierarchy and Grounding

A fundamental tenet of MOCS-Cert is the strict separation between computational certification and empirical physical reality. The system never claims that a certified result establishes experimental truth or continuous physical behavior.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Experimental Truth (Wet-lab observation, in vitro/vivo)  │
│    ▲ (Outside the scope of MOCS-Cert)                       │
├────┼────────────────────────────────────────────────────────┤
│ 2. Physical Truth (Continuous Hamiltonian dynamics in R^3N) │
│    ▲ (Approximated by numerical integrators and forcefields)│
├────┼────────────────────────────────────────────────────────┤
│ 3. Simulation Truth (Trajectory produced by simulation code)│
│    ▲ (Subject to integration error, drift, barostat artifacts)│
├────┼────────────────────────────────────────────────────────┤
│ 4. Data-Level Truth (Discrete byte stream in XTC/DCD file)  │
│    ▲ (Authoritative input to MOCS-Cert)                     │
├────┼────────────────────────────────────────────────────────┤
│ 5. Certified Derivation (Sound derivation relative to C)    │
│    • MOCS-Cert Operates Exclusively at this Layer           │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 Strict Epistemic Distinctions

1. **Data-Level Truth:** Statements that strictly and deterministically hold regarding the binary contents of the declared trajectory and topology files under the specified coordinate decoder.
2. **Simulation Truth:** Statements about the mathematical dynamical system modeled by the molecular dynamics engine (e.g., GROMACS, NAMD). This depends on integration algorithms, thermostat/barostat couplings, cutoffs, and force-field parameterizations. MOCS-Cert does **not** validate simulation fidelity.
3. **Physical Truth:** The actual quantum-mechanical and thermodynamic behavior of the real molecular ensemble in nature. Simulation is an approximation; MOCS-Cert makes no claim to bridge this gap.
4. **Experimental Truth:** Results obtained via biophysical laboratory assays (e.g., NMR, X-ray crystallography, Cryo-EM, FRET). Experimental measurements possess measurement error and ensemble averaging outside MOCS-Cert's purview.

### 1.2 The Certification Contract Guarantee

A certificate generated by MOCS-Cert attests exclusively to the following:

$$\text{Certificate} \iff \text{Sound derivation from } (T, \Phi, \mathcal{O}, \Pi, \Sigma, \Omega, \mathcal{C})$$

Where:
* $T$: Source trajectory data uniquely identified by cryptographic hash $H(T)$.
* $\Phi$: Declared molecular topology uniquely identified by cryptographic hash $H(\Phi)$.
* $\mathcal{O}$: Immutable versioned operator definitions (e.g., `DISTANCE-v1`, `HBOND-v1`).
* $\Pi$: Explicit numerical policy (floating-point precision, IEEE-754 rounding, algebraic sequence).
* $\Sigma$: Declared sampling semantics (strictly sampled frames; continuous physical interpolation is explicitly unsupported).
* $\Omega$: Periodic boundary condition semantics (orthorhombic minimum-image convention on a fixed cell).
* $\mathcal{C}$: The user-declared Observability Contract $\mathcal{C} = (Q, \epsilon, \tau, \text{policy})$.

## 2. Molecular Data Primitives

### 2.1 The Trajectory

**Definition (Trajectory).** A trajectory $T$ is an ordered, finite sequence of discrete temporal frames:

$$T = \langle f_0, f_1, f_2, \dots, f_{N-1} \rangle$$

where $N = |T| \in \mathbb{N}_{>0}$ is the total frame count. $T$ represents sampled coordinate states recorded at discrete simulation instants, **not** a continuous trajectory curve $x(t)$.

### 2.2 The Frame

**Definition (Frame).** A frame $f_k \in T$ is a 3-tuple:

$$f_k = (\mathbf{X}_k, \mathbf{B}_k, t_k)$$

where:
* $\mathbf{X}_k \in \mathbb{R}^{n \times 3}$ is the Cartesian coordinate matrix for all $n$ atoms in the system at frame index $k$.
* $\mathbf{B}_k \in \mathbb{R}^{3 \times 3}$ is the simulation box tensor at frame index $k$. In V0.1, the simulation cell is restricted to a fixed, time-invariant orthorhombic box:
  $$\mathbf{B}_k = \operatorname{diag}(L_x, L_y, L_z), \quad \forall k \in \{0, \dots, N-1\}, \quad L_x, L_y, L_z > 0$$
* $t_k \in \mathbb{R}_{\ge 0}$ is the physical simulation timestamp assigned to frame $k$, typically expressed in picoseconds ($\text{ps}$).

### 2.3 The Atom

**Definition (Atom).** An atom $\alpha_i$ ($i \in \{0, \dots, n-1\}$) is an indivisible coordinate entity whose spatial location at frame $f_k$ is given by row $i$ of the coordinate matrix:

$$\mathbf{x}_i(k) = \mathbf{X}_k[i, :] = (x_i(k), y_i(k), z_i(k)) \in \mathbb{R}^3$$

Each atom $\alpha_i$ possesses static categorical attributes defined in the topology $\Phi$:
* Unique global index: $i \in \{0, \dots, n-1\}$
* Residue index: $\operatorname{res\_idx}(\alpha_i) \in \mathbb{N}$
* Residue name: $\operatorname{res\_name}(\alpha_i) \in \mathbb{S}$ (e.g., `"ALA"`, `"LIG"`)
* Atom name: $\operatorname{atom\_name}(\alpha_i) \in \mathbb{S}$ (e.g., `"CA"`, `"O2"`, `"HN"`)
* Element / Chemical Type: $\operatorname{element}(\alpha_i) \in \mathbb{S}$

### 2.4 The Topology

**Definition (Topology).** The topology $\Phi$ is an immutable attributed graph:

$$\Phi = (\mathcal{A}, \mathcal{E}, \mathcal{M})$$

where:
* $\mathcal{A} = \{\alpha_0, \alpha_1, \dots, \alpha_{n-1}\}$ is the set of all system atoms.
* $\mathcal{E} \subseteq \mathcal{A} \times \mathcal{A}$ is the static covalent bond connectivity graph.
* $\mathcal{M}$ is the chemical metadata mapping assigning partial charges, masses, and donor/acceptor roles.

**Static Topology Invariant (V0.1):** The topology $\Phi$ is static across the entire trajectory $T$. Reactive processes, proton transfer, bond breaking/forming, and variable atom counts are explicitly unsupported in V0.1.

### 2.5 The Simulation Box and Periodic Boundary Space

**Definition (Simulation Cell).** In V0.1, the periodic simulation cell $\Omega$ is defined as the half-open orthorhombic domain:

$$\Omega = [0, L_x) \times [0, L_y) \times [0, L_z) \subset \mathbb{R}^3$$

All spatial analysis is conducted under the minimum-image convention (MIC). For any pair of coordinates $\mathbf{x}_i, \mathbf{x}_j \in \Omega$, the minimum image displacement vector $\boldsymbol{\delta} = (\delta_x, \delta_y, \delta_z)$ is defined coordinate-wise:

$$\delta_\mu = (x_{j,\mu} - x_{i,\mu}) - L_\mu \cdot \operatorname{round}\left(\frac{x_{j,\mu} - x_{i,\mu}}{L_\mu}\right), \quad \mu \in \{x, y, z\}$$

where $\operatorname{round}(u) = \lfloor u + 0.5 \rfloor$ with standard IEEE-754 tie-breaking rules.

**Scalar Distance Uniqueness:** The scalar minimum-image distance $d = \|\boldsymbol{\delta}\|_2$ is uniquely defined for all coordinate pairs in $\Omega$. When $|x_{j,\mu} - x_{i,\mu}| = L_\mu/2$, the displacement vector has two antipodal representations ($\pm L_\mu/2$); deterministic tie-breaking selects one, but the scalar distance $\|\boldsymbol{\delta}\|_2$ is identical under both representations.

### 2.6 Sampling Interval

**Definition (Sampling Interval).** The nominal temporal sampling step is:

$$\Delta t_k = t_{k+1} - t_k, \quad k \in \{0, \dots, N-2\}$$

**Uniform Sampling Invariant (V0.1):** Trajectories evaluated in V0.1 are assumed to possess uniform sampling intervals:

$$\Delta t_k = \Delta t = \text{const} > 0, \quad \forall k$$

If non-uniform sampling timestamps or missing frames are encountered, the compiler issues an `UNRESOLVABLE_SAMPLING` diagnostic when physical duration bounds cannot be soundly mapped to discrete frame counts.

## 3. Observable Operator Semantics

An observable operator $\mathcal{O}$ is a pure mathematical functional mapping atom coordinates and simulation metadata at a given frame $f_k$ to a physical value or Boolean observation. In V0.1, operands are strictly single-atom selections.

### 3.1 DISTANCE Operator

**Signature:** $\operatorname{DISTANCE}(\alpha_i, \alpha_j, \Omega) \to \mathbb{R}_{\ge 0}$  
**Units:** $\text{Å}$ ($\text{default}$), $\text{nm}$ (upon conversion).

**Exact Per-Frame Evaluator:**
For two atoms $\alpha_i, \alpha_j \in \mathcal{A}$ in frame $f_k$:

$$d_{ij}(k) = \|\boldsymbol{\delta}(k)\|_2 = \sqrt{\delta_x(k)^2 + \delta_y(k)^2 + \delta_z(k)^2}$$

where $\boldsymbol{\delta}(k)$ is the minimum-image displacement in cell $\Omega$.

### 3.2 CONTACT Operator

**Signature:** $\operatorname{CONTACT}(\alpha_i, \alpha_j, \theta, \Omega) \to \{\text{TRUE}, \text{FALSE}\}$  
**Inputs:** Atoms $\alpha_i, \alpha_j$, distance cutoff threshold $\theta \in \mathbb{R}_{>0}$.

**Exact Per-Frame Evaluator:**

$$\operatorname{CONTACT}(\alpha_i, \alpha_j, \theta)(k) = \begin{cases} 
\text{TRUE} & \text{if } d_{ij}(k) < \theta \\ 
\text{FALSE} & \text{if } d_{ij}(k) \ge \theta 
\end{cases}$$

**Numerical Boundary Policy:**
If $|d_{ij}(k) - \theta| \le \epsilon_{\text{mach}}$ (where $\epsilon_{\text{mach}} = 10^{-6}\text{ \AA}$), floating-point rounding may introduce ambiguity. Such evaluations are classified as `UNKNOWN` with resolution status `NEEDS_REFINEMENT` and diagnostic flag `NUMERICAL_BOUNDARY_AMBIGUITY`.

### 3.3 HBOND Operator

**Signature:** $\operatorname{HBOND}(D, H, A, d_{\text{cutoff}}, \theta_{\text{cutoff}}, \Phi, \Omega) \to \{\text{TRUE}, \text{FALSE}\}$  
**Inputs:**
* Donor heavy atom: $D \in \mathcal{A}$ (e.g., Nitrogen, Oxygen).
* Hydrogen atom: $H \in \mathcal{A}$ covalently bonded to $D$ in $\Phi$ ($(D, H) \in \mathcal{E}$).
* Acceptor heavy atom: $A \in \mathcal{A}$ (e.g., Oxygen, Nitrogen).
* Distance cutoff: $d_{\text{cutoff}} \in \mathbb{R}_{>0}$ (default $3.5\ \text{Å}$ between $D$ and $A$).
* Angle cutoff: $\theta_{\text{cutoff}} \in [0, 180^\circ]$ (default $120^\circ$ for $\angle(D - H \cdots A)$).

**Exact Per-Frame Evaluator:**
$\operatorname{HBOND}(D, H, A)(k) = \text{TRUE}$ if and only if the following conjunction holds:
1. **Topology Requirement:** $(D, H) \in \mathcal{E}$ and $D \ne A$ and $H \ne A$.
2. **Distance Criterion:** $d_{DA}(k) = \operatorname{DISTANCE}(D, A, \Omega)(k) < d_{\text{cutoff}}$.
3. **Angular Criterion:** Let $\mathbf{v}_{HD} = \mathbf{x}_D(k) - \mathbf{x}_H(k)$ and $\mathbf{v}_{HA} = \mathbf{x}_A(k) - \mathbf{x}_H(k)$ under minimum image relative to $H$:
   $$\cos \theta_{DHA}(k) = \frac{\mathbf{v}_{HD} \cdot \mathbf{v}_{HA}}{\|\mathbf{v}_{HD}\|_2 \|\mathbf{v}_{HA}\|_2}$$
   $$\theta_{DHA}(k) = \arccos\left(\operatorname{clamp}\left(\cos \theta_{DHA}(k), -1.0, 1.0\right)\right) \ge \theta_{\text{cutoff}}$$

**Two-Stage Evaluation Pipeline (V0.1):**
* **Stage 1 (Conservative Block Pruning):** Distance bounds are computed on the donor-acceptor pair $d_{DA}$. If $L(d_{DA}) \ge d_{\text{cutoff}}$ for block $B_m$, the block is certified `FALSE` without evaluating angles or reading coordinate frames.
* **Stage 2 (Exact Frame Evaluation):** Blocks where Stage 1 returns `UNKNOWN` undergo exact frame-by-frame evaluation of both distance and angle criteria. Block-level certification of HBOND via angular AABB bounds is an open research problem and is explicitly not performed in V0.1.

## 4. Temporal Predicates and Discrete Event Algebra

Temporal predicates operate exclusively on discrete frame sequences under strictly sampled-frame semantics.

### 4.1 Sampled-Frame Event Model (Half-Open Intervals)

Let $P: T \to \{\text{TRUE}, \text{FALSE}\}$ be a frame-level observable predicate. Evaluating $P$ over trajectory $T$ produces a discrete Boolean indicator sequence:

$$\sigma_P = \langle P(f_0), P(f_1), \dots, P(f_{N-1}) \rangle \in \{0, 1\}^N$$

**Definition (Event Interval).** A sampled-frame event interval $E$ of predicate $P$ is a half-open contiguous index interval $E = [k_s, k_e) \subset \mathbb{N}$ such that:
1. $P(f_k) = \text{TRUE}$ for all $k \in \{k_s, k_s + 1, \dots, k_e - 1\}$.
2. $k_s = 0 \lor P(f_{k_s - 1}) = \text{FALSE}$ (maximal start).
3. $k_e = N \lor P(f_{k_e}) = \text{FALSE}$ (maximal end).

$k_e$ is the frame index strictly after the conclusion of the event.

### 4.1 Sample-Slot Axiom and Event Intervals

**Axiom (Sample-Slot Semantics).** In MOCS-Cert V0.1, simulation trajectories are evaluated strictly under sampled-frame semantics (`mode: sampled_frames`). Each discrete frame $k \in \{0, 1, \dots, N-1\}$ occupies the half-open temporal slot:

$$I_k = [t_k, t_{k+1}) = [k \Delta t, (k+1)\Delta t)$$

with sample-slot duration $\Delta t$. A predicate $P$ holding `TRUE` at frame $f_k$ asserts truth throughout slot $I_k$. MOCS-Cert makes zero mathematical claims regarding continuous coordinates or inter-frame trajectory excursions between discrete sampled timepoints. Requests for continuous-time physical persistence (`mode: continuous_physical`) are outside V0.1 capabilities and emit `resolution: UNSUPPORTED_SEMANTICS`.

**Definition (Event Interval).** An event episode $E$ is a maximal sequence of contiguous frames satisfying predicate $P$, represented as the half-open integer interval:

$$E = [k_s, k_e) = \{k \in \mathbb{N}_0 \mid k_s \le k < k_e\}$$

satisfying:
1. $\forall k \in [k_s, k_e) : P(f_k) = \text{TRUE}$
2. $k_s = 0 \lor P(f_{k_s - 1}) = \text{FALSE}$ (maximal start)
3. $k_e = N \lor P(f_{k_e}) = \text{FALSE}$ (maximal exclusive end).

$k_e$ is strictly the first frame index *after* the conclusion of the event.

**Definition (Sampled Duration).** The elapsed duration of event $E = [k_s, k_e)$ is:

$$\operatorname{Duration}(E) = (k_e - k_s) \cdot \Delta t$$

*Example:* A run of 100 consecutive `TRUE` frames starting at index 0 forms interval $[0, 100)$, with duration $(100 - 0) \times 10\text{ ps} = 1000\text{ ps}$. A single `TRUE` frame at index $k$ forms interval $[k, k+1)$, with duration $(k+1 - k)\Delta t = \Delta t$.

### 4.2 Definite vs. Possible Event Sets and FOR Operator

During hierarchical execution, blocks may be CERTIFIED_TRUE, CERTIFIED_FALSE, or UNKNOWN. To soundly certify temporal properties before full frame decoding, MOCS-Cert constructs two event sets:

1. **Definite Events ($\mathcal{E}_P^{\text{def}}$):** Contiguous runs composed strictly of verified `TRUE` blocks or exact frames. Every $E \in \mathcal{E}_P^{\text{def}}$ is guaranteed to occur.
2. **Possible Events ($\mathcal{E}_P^{\text{poss}}$):** Contiguous runs composed of `TRUE` and `UNKNOWN` blocks or frames, bounded by certified `FALSE` barriers. Any actual event is a subset of a possible event.

**Signature:** $\operatorname{FOR}(P, \tau) \to \{\text{TRUE}, \text{FALSE}, \text{UNKNOWN}\}$  
**Definition:** $\operatorname{FOR}(P, \tau)$ asserts that an unbroken run of sampled frames satisfying $P$ spans at least duration $\tau$:

$$\operatorname{FOR}_{\text{sampled}}(P, \tau) \iff \exists E \in \mathcal{E}_P : \operatorname{Duration}(E) \ge \tau \iff (k_e - k_s) \ge \left\lceil \frac{\tau}{\Delta t} \right\rceil$$

* **Certified TRUE:** $\exists E \in \mathcal{E}_P^{\text{def}} : \operatorname{Duration}(E) \ge \tau$.
* **Certified FALSE:** The maximum possible contiguous run through unrefuted (`TRUE` $\cup$ `UNKNOWN`) frames is strictly less than $\tau$:
  $$\max_{E \in \mathcal{E}_P^{\text{poss}}} \operatorname{Duration}(E) < \tau$$
  If even an unbroken run through all candidate `UNKNOWN` blocks cannot achieve $\lceil \tau / \Delta t \rceil$ frames, the query is soundly certified `FALSE` without further refinement.
* **UNKNOWN (NEEDS_REFINEMENT):** $\max_{E \in \mathcal{E}_P^{\text{poss}}} \operatorname{Duration}(E) \ge \tau$, but no $E \in \mathcal{E}_P^{\text{def}}$ satisfies the threshold. Dyadic refinement or exact frame scanning is required.
* **Sub-Frame Queries ($\tau \le \Delta t$ under Sampled Semantics):** Under sampled-frame semantics, $\lceil \tau / \Delta t \rceil = 1$. A query $\operatorname{FOR}(P, 2\text{ ps})$ on a trajectory with $\Delta t = 10\text{ ps}$ is satisfied by any single `TRUE` frame ($1 \times 10\text{ ps} \ge 2\text{ ps}$).

### 4.3 BEFORE and AFTER Operators

Let $\mathcal{E}_A$ and $\mathcal{E}_B$ be the sets of event intervals for predicates $P_A$ and $P_B$.

**Occurrence Semantics (V0.1 Canonical Existential):**
$$\operatorname{BEFORE}_{\text{exists}}(P_A, P_B) \iff \exists E_A = [a_s, a_e) \in \mathcal{E}_A, \, \exists E_B = [b_s, b_e) \in \mathcal{E}_B : a_e \le b_s$$

* **`TRUE`**: A verified pair satisfies $a_e \le b_s$ (event $A$ concludes at or before frame $b_s$, where $B$ begins).
* **`FALSE`**: Either $\mathcal{E}_A = \emptyset$ (certified complete), $\mathcal{E}_B = \emptyset$ (certified complete), or for all pairs $(E_A, E_B)$, $a_e > b_s$.
* **`UNKNOWN`**: Ordering cannot be proven due to candidate `UNKNOWN` blocks in $\mathcal{E}^{\text{poss}}$.

**Empty Event Truth Table (Canonical Closed-World / Existential):**
| $\mathcal{E}_A$ Status | $\mathcal{E}_B$ Status | Operator | Truth Value | Resolution Status |
|:---|:---|:---|:---:|:---:|
| Definitive $\emptyset$ | Non-empty | BEFORE / AFTER / WITHIN / FOLLOWED_BY | `FALSE` | `COMPLETE` |
| Non-empty | Definitive $\emptyset$ | BEFORE / AFTER / WITHIN / FOLLOWED_BY | `FALSE` | `COMPLETE` |
| Definitive $\emptyset$ | Definitive $\emptyset$ | BEFORE / AFTER / WITHIN / FOLLOWED_BY | `FALSE` | `COMPLETE` |
| Candidate (contains UNKNOWN) | Any | Any Temporal Operator | `UNKNOWN` | `NEEDS_REFINEMENT` |

$\operatorname{AFTER}(P_A, P_B)$ is defined symmetrically: $b_e \le a_s$.

### 4.4 FOLLOWED_BY Operator

**Signature:** $\operatorname{FOLLOWED\_BY}(P_A, P_B, W_{\max}) \to \{\text{TRUE}, \text{FALSE}, \text{UNKNOWN}\}$  
**Semantics:** Asserts that an occurrence of $A$ finishes before an occurrence of $B$ begins, with elapsed lag between $a_e$ and $b_s$ not exceeding $W_{\max}$:

$$E_A \operatorname{FOLLOWED\_BY} E_B \iff (a_e \le b_s) \land \left((b_s - a_e) \cdot \Delta t \le W_{\max}\right)$$

* **`TRUE`**: A verified pair $(E_A, E_B)$ satisfies the condition.
* **`FALSE`**: For all candidate pairs in $\mathcal{E}^{\text{poss}}$, either $a_e > b_s$ or $(b_s - a_e)\Delta t > W_{\max}$, or one event set is definitively empty.
* **`UNKNOWN`**: Unresolved blocks leave ordering or lag ambiguous.

### 4.5 WITHIN Operator

**Signature:** $\operatorname{WITHIN}(P_A, P_B, W_{\text{window}}) \to \{\text{TRUE}, \text{FALSE}, \text{UNKNOWN}\}$  
**Pairwise Metric & Quantifier:** Under existential occurrence semantics, $\operatorname{WITHIN}$ asserts:

$$\min_{E_A \in \mathcal{E}_A, \, E_B \in \mathcal{E}_B} \operatorname{dist}(E_A, E_B) \le W_{\text{window}}$$

where for half-open intervals $E_A = [a_s, a_e)$ and $E_B = [b_s, b_e)$:

$$\operatorname{dist}(E_A, E_B) = \max(0, \, b_s - a_e, \, a_s - b_e) \cdot \Delta t$$

If $E_A$ and $E_B$ overlap in time ($a_s < b_e \land b_s < a_e$), $\operatorname{dist}(E_A, E_B) = 0$.

## 5. Result Semantics and Epistemic Separation

MOCS-Cert strictly separates **Logical Truth** from **Execution Resolution Status**, replacing previous conflated "six-state epistemic logic" formulations.

```
                      QUERY INGESTION
                             │
                             ▼
                    CONTRACT COMPILATION
                             │
              ┌──────────────┴──────────────┐
              ▼                             ▼
       INDEX EVALUATION              DIRECT SOURCE SCAN
              │                             │
              ▼                             ▼
       CONSERVATIVE BOUNDS             EXACT VALUES
              │                             │
              └──────────────┬──────────────┘
                             ▼
                    EPISTEMIC EVALUATION
                             │
              ┌──────────────┴──────────────┐
              ▼                             ▼
       LOGICAL TRUTH (T)            EXECUTION STATUS (R)
         • TRUE                       • COMPLETE
         • FALSE                      • NEEDS_REFINEMENT
         • UNKNOWN                    • UNRESOLVABLE_SAMPLING
                                      • UNSUPPORTED_GEOMETRY
                                      • UNSUPPORTED_SEMANTICS
                                      • ERROR
```

### 5.1 The Logical Truth Domain ($\mathbb{T}$)

$$\mathbb{T} = \{\text{TRUE},\, \text{FALSE},\, \text{UNKNOWN}\}$$

Logic operations on $\mathbb{T}$ follow Kleene's strong 3-valued logic:

| $A$ | $B$ | $A \land B$ | $A \lor B$ | $\neg A$ |
|:---:|:---:|:---:|:---:|:---:|
| TRUE | TRUE | TRUE | TRUE | FALSE |
| TRUE | FALSE | FALSE | TRUE | FALSE |
| TRUE | UNKNOWN | UNKNOWN | TRUE | FALSE |
| FALSE | FALSE | FALSE | FALSE | TRUE |
| FALSE | UNKNOWN | FALSE | UNKNOWN | TRUE |
| UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |

### 5.2 The Execution Resolution Status Domain ($\mathbb{R}$)

$$\mathbb{R} = \{\text{COMPLETE},\, \text{NEEDS\_REFINEMENT},\, \text{UNRESOLVABLE\_SAMPLING},\, \text{UNSUPPORTED\_GEOMETRY},\, \text{UNSUPPORTED\_SEMANTICS},\, \text{ERROR}\}$$

* **`COMPLETE`**: Logical truth is definitively resolved (`TRUE` or `FALSE`). Execution finished.
* **`NEEDS_REFINEMENT`**: Logical truth is `UNKNOWN`. Reading further coordinate frames or subdividing blocks can resolve the query.
* **`UNRESOLVABLE_SAMPLING`**: The query asserts conditions that cannot be answered due to missing, irregular, or corrupt trajectory timestamps. Reading additional frames cannot resolve missing temporal registration.
* **`UNSUPPORTED_GEOMETRY`**: Trajectory features (e.g. non-orthorhombic triclinic cells, variable-volume boxes) violate V0.1 engine preconditions. Fails closed.
* **`UNSUPPORTED_SEMANTICS`**: Requested execution mode (e.g. continuous physical interpolation `mode: continuous_physical`) is not supported by V0.1 discrete sampled runtime.
* **`ERROR`**: System failure (corrupted trajectory file, missing topology, checksum mismatch, unhandled I/O exception, zero-vector geometric singularity).

*(Note on Algorithmic Bound Conditions: Large per-frame coordinate displacement exceeding $L_\mu / 4$ triggers internal `BOUND_CONSTRUCTION_UNAVAILABLE`. This is an algorithmic limitation of AABB envelope construction, NOT an unsupported geometry. It soundly resolves to `truth: UNKNOWN, resolution: NEEDS_REFINEMENT`, safely triggering sub-block refinement or exact frame fallback).*

### 5.3 Block-Level Certification vs. Query-Level Aggregation

A critical architectural distinction is maintained between block-level certificates and query-level results:

1. **Block-Level Certificate ($c(B_m) \in \mathbb{T}$):**  
   Evaluates whether predicate $P(k)$ holds for *all* frames in temporal block $B_m$:
   $$c(B_m) = \begin{cases}
   \text{TRUE} & \text{if } \forall k \in B_m : P(k) = \text{TRUE} \\
   \text{FALSE} & \text{if } \forall k \in B_m : P(k) = \text{FALSE} \\
   \text{UNKNOWN} & \text{otherwise}
   \end{cases}$$

2. **Query-Level Quantifiers:**  
   The scientific query explicitly declares its quantifier:
   * **Existential Query ($\exists k : P(k)$):**
     * `TRUE` certified if $\exists B_m : c(B_m) = \text{TRUE}$ or any exact frame has $P(k) = \text{TRUE}$.
     * `FALSE` certified only if $\forall B_m : c(B_m) = \text{FALSE}$ across the complete scope with verified coverage.
     * `UNKNOWN` otherwise.
   * **Universal Query ($\forall k : P(k)$):**
     * `TRUE` certified only if $\forall B_m : c(B_m) = \text{TRUE}$ across the complete scope with verified coverage.
     * `FALSE` certified if $\exists B_m : c(B_m) = \text{FALSE}$ or any exact frame has $P(k) = \text{FALSE}$.
     * `UNKNOWN` otherwise.
   * **Duration Query ($\operatorname{FOR}(P, \tau)$):**
     * `TRUE` certified if a contiguous run of verified `TRUE` frames/blocks spans $\ge \tau$.
     * `FALSE` certified if the maximum possible contiguous run through `TRUE` $\cup$ `UNKNOWN` is $< \tau$.
     * `UNKNOWN` otherwise.
